# Minipass Documentation

Start with `../AGENTS.md` for the agent-level rules, or `../README.md` to set up and run the app.

## Active docs

| Doc | Purpose | When to read |
|---|---|---|
| `PRODUCT.md` | What Minipass is, who it serves, core flows | Before any feature work |
| `ARCHITECTURE.md` | Stack, models, routes, integrations, migrations | Before backend or schema changes |
| `DESIGN.md` | Page-by-page UI/UX workflow and quality rules | Before any template/CSS work |
| `EMAIL.md` | Email system, design language, and how to test all 7 templates | Before touching email templates or sending |
| `CHANGELOG.md` | Shipped features, improvements, and fixes by date | To see what changed and when |

Testing rules live in `../AGENTS.md` (hard rules 4–7) and `../README.md`. Email-specific testing is in `EMAIL.md`.

## Archive

Old docs live in `.archive/`, which is not tracked in git. They are historical only and not authoritative.
