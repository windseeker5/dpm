{# Reusable pagination macro following Tabler.io standards Usage: {% from 'macros/pagination.html' import render_pagination %} {{ render_pagination(pagination, current_filters, items) }} Parameters: - pagination: Flask-SQLAlchemy pagination object - current_filters: Dict of current query parameters to preserve (e.g., {'q': 'search', 'status': 'active'}) - items: Current page's items list (for accurate entry counter) - page_param: Optional name of the page parameter (default: 'page'). Use for multi-table pagination (e.g., 'passport_page', 'signup_page') #} {# Pagination — Desktop / Mobile (mp-* styled, style-guide component). Unlike render_pagination() above, these take plain values instead of a Flask-SQLAlchemy Pagination object and don't call url_for(request.endpoint, ...) — so they're demo-able in the style guide with base_path="#" and don't need a real list-view request context. A real page adopting these later passes base_path=request.path and its existing current_filters dict (every list page already builds one for render_pagination() today). The current-page indicator uses --mp-brand-primary (mp-components.css), not a hardcoded color — see that variable's own comment for why (future per-tenant branding color, same pattern as --mp-chart-1). Usage: {% from 'macros/pagination.html' import pagination_desktop, pagination_mobile %} {{ pagination_desktop(page=2, pages=9, per_page=5, total=43, items_count=5, base_path=request.path, filters=current_filters) }} {{ pagination_mobile(page=2, pages=9, per_page=5, total=43, items_count=5, base_path=request.path, filters=current_filters) }} Parameters (both): - page: current page number (1-indexed) - pages: total number of pages - per_page: items per page - total: total item count across all pages - items_count: number of items on the CURRENT page (usually per_page, except a possibly-shorter last page) - base_path: URL path to link to (e.g. request.path) - filters: dict of extra query params to preserve, e.g. {"status": "active"} - page_param: query param name for the page number, default "page" - window (pagination_desktop only): how many page numbers to show on each side of the current page before collapsing into "…", default 2 #} {% macro pagination_desktop(page, pages, per_page, total, items_count, base_path, filters={}, page_param='page', window=2) %}
