{# Avatar (Initials) — colored-circle avatar generated from a name, no network request. Replaces the Gravatar-identicon `` pattern used by the live passports/signups/activities tables (a random pattern requiring a per-row request to gravatar.com with the user's email hashed into the URL) — same initials-avatar approach as Gmail/Slack. Color is picked deterministically from a hash of the name (not random per render) using the app's existing `encode_md5` Jinja filter (app.py's @app.template_filter('encode_md5')), bucketed into one of Tabler's own `bg-*-lt`/`text-*-lt-fg` color pairs — reusing the same palette already used for the Paid/Unpaid badges instead of inventing a new color system. Falls back to avatar_initials() at the call site when there's no photo — this macro itself always renders an .
