Style Guide

The only components you should ever need. Never hand-roll a button, a dropdown, or a heading size — use these.

Typography

Fixed scale, Inter, one family. Headings are global (h1-h5) — never override size/color/font on a page.

H1 — Page title (24px / 600)

H2 — Section title (20px / 600)

H3 — Card / subsection title (18px / 600)

H4 — Minor heading (16px / 600)

H5 — Label / eyebrow (14px / 600, uppercase)

Body — description / secondary text (14px / 400). This is the .mp-text-body class.
